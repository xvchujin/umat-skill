# 显式屈服漂移的残差改进、回滚与有界退出

## I — 方法论骨架 (Interpretation)

屈服漂移是显式离散后候选塑性状态没有落在目标屈服面上，即尺度化 `|f(σ,q)|` 超过容差。
它发生在候选子步之后，与加载路径首次触面 `α` 搜索是不同阶段。
修正前必须保存应力和全部耦合内部变量的基准快照，并把该快照作为每个备选方向的共同起点。
一次修正由方向、标量幅值和联合状态更新规则组成；三者都必须与模型的 `f`、流动法则和变量约定一致。
修正不是因为公式执行完就接受，而要重新评价完整屈服函数并要求残差严格改善且状态仍在物理域。
若首选方向使 `|FNEW|>|F0|`，应恢复到未修正快照，再切换到更保守、可验证的方向；不能从坏修正上继续叠加。
每轮都要设置残差容差、最小进展和最多次数；停滞或预算耗尽必须回滚并升级失败。
这是一种显式积分后的投影/漂移修复，不是隐式 return mapping，也不自动给出一致切线或真实塑性乘子。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 显式塑性积分结束后 `|f|` 超过屈服容差，但嵌入误差 `η_emb` 已合格。
2. 漂移随子步累计，材料点逐渐离开屈服面或出现非物理硬化/软化。
3. 应力投影后残差反而更大，需要 rollback、fallback direction 或 safeguarded correction。
4. 修正应力时还必须同步修正硬化、织构、孔隙比等耦合状态。
5. 正在审查 `SDRIFT`、yield drift、projection、normal correction、residual improvement。

### 语言信号 (用户的话里出现这些就应激活)

- “显式积分后不在屈服面 / yield-surface drift”
- “FNEW 比 F0 还大 / correction worsens residual”
- “修正失败要不要回滚 / rollback before fallback”
- “沿屈服面法向投影 / normal projection”
- “漂移修正迭代死循环 / bounded correction”

### 与相邻 skill 的区分

- 与 `explicit-alpha-yield-intersection`：后者在弹性试探路径上找首次触面；本 skill 处理塑性子步终点的约束漂移。
- 与 `explicit-adaptive-substepping`：后者用嵌入差 `η_emb` 控制局部离散误差；本 skill 用屈服残差检查约束一致性，两门都应通过。
- 与 `umat-failure-cutback-protocol`：本 skill 在有限预算内尝试局部修复；后者接管修复失败后的干净回滚和全局增量请求。
- 与隐式 return mapping：本 skill 是后处理式显式修正，不把 `Δλ`、应力和状态作为一个 Newton 系统联立求解。

## E — 可执行步骤 (Execution)

1. **定义漂移残差和尺度**
   - 在本模型的应力、内部变量和符号约定下定义 `F=f(σ,q)`，给出尺度化 `r=|F|/F_scale`、容差 `tol_f`、最小相对改善率和修正预算。
   - 完成标准：同一物理状态在合理单位变换下不会因裸阈值改变合格结论；目标是哪个屈服面/分支明确。
   - 判停路径：屈服函数、导数或尺度未定义、非有限，或状态位于模型禁止域时，不启动修正，直接返回域失败。

2. **先通过子步候选的其他验收门**
   - 确认候选状态来自同一起点的完整积分，局部误差 `η_emb`、有限数和基本物理域已检查；漂移门独立记录。
   - 完成标准：能够区分“积分误差超限”和“约束漂移超限”；前者应拒绝/缩小局部 `DT`，不应靠投影掩盖。

3. **保存未修正联合状态快照**
   - 保存 `σ_0`、全部 `q_0`、能量/辅助输出和 `F0`；所有修正先写 trial 缓冲区。
   - 完成标准：任一备选失败后可逐分量恢复，且恢复后的残差精确回到 `F0`。

4. **从模型方程推导首选修正**
   - 明确方向、分母和标量幅值；应力与内部变量的修正式分别做维度、符号和方向导数检查，不照抄讲义中有争议的 `De` 或正负号。
   - 完成标准：小扰动检验显示所选方向的一阶变化与推导一致，分母远离零或有可辩护的保护分支。
   - 判停路径：方向导数非有限、近零或预测残差不降时，跳过该方向并进入安全备选，而不是除以极小数。

5. **试算后重新评价完整残差**
   - 对 trial 的应力和全部已修正内部变量重新调用原屈服函数，得到 `FNEW`；同时复查可容许域和变量边界。
   - 完成标准：只有 `|FNEW|<|F0|`（考虑明确的最小进展阈值）且物理门全过时，才把该 trial 作为下一轮基准；若 `r≤tol_f` 则成功退出。

6. **变坏或停滞时回滚并切换方向**
   - 若残差增大、方向错误或进展不足，完全恢复未修正快照，再从该快照尝试法向/限幅备选；必要时使用线搜索保持残差下降。
   - 完成标准：备选不是叠加在失败 trial 上；每轮日志能重建所用方向、幅值、修正前后残差。
   - 判停路径：所有可辩护方向均不能下降时，停止本轮修正并把子步判失败。

7. **有界迭代与最终提交**
   - 每轮递增计数，检查残差、最小进展、变量边界和非有限数；成功时一次性提交联合状态。
   - 完成标准：返回成功必有 `r≤tol_f`、有限状态和完整变量一致性；不会以“次数用完”当作成功。
   - 判停路径：达到配置的最大次数、残差振荡/停滞、步幅退化或状态越界时，恢复子步起点并交给失败/cutback 协议。

8. **做方法与步长敏感性验证**
   - 比较无修正、首选修正、备选修正及更小局部 `DT` 的结果，跟踪残差、状态变化和能量/耗散。
   - 完成标准：修正不会成为主导材料响应的隐藏积分器；随 `DT` 缩小，修正量应呈可解释趋势。

## B — 边界 (Boundary)

### 五个控制量必须隔离

- `α`：当前总路径的首次弹性屈服交点比例；漂移修正发生在该交点之后，不能重新解释 `α`。
- 局部 `DT`：显式塑性子路径的步长；减小它可减少漂移，但它不是修正幅值。
- `Δλ`：隐式一致性/塑性流动乘子；后修正中出现的标量即使量纲相似，也不能未经推导称为真实 `Δλ`。
- `PNEWDT`：局部修正失败后可向 Abaqus提出的全局增量比例建议；它不是某一轮修正步长。
- `η_emb`：嵌入解差给出的局部截断误差代理；`η_emb≤tol` 不蕴含屈服残差 `|F|≤tol_f`，反之亦然。`η_emb` 与 Tsai-Wu 失效指数 `e` 也不可混用。

### 不要在以下情况使用此 skill

- 候选子步自身误差超限：先拒绝并缩小局部 `DT`，不要投影坏积分结果。
- 需要找到从弹性到塑性的首次交点：使用 α 交点 skill。
- 需要严格的一致隐式返回映射或一致 Jacobian：后修正不能替代联立求解及其线性化。
- 屈服面不可微、存在角点或多面切换，却没有定义合法投影/活动面规则。
