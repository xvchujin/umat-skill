# 木材受损六维算子闭包

## I — 方法论骨架

1. 木材正交各向异性刚度是耦合的六维算子，只退化对角项通常会破坏泊松互易或正定性。
2. 先在积分点材料轴内构造受损柔度或刚度，再按 Abaqus 约定映射和旋转。
3. 每个损伤变量必须有明确的法向、剪切和耦合项影响范围，多个模式需要声明组合顺序。
4. `d` 接近 1 时要区分物理完全失效、残余刚度近似和数值删除；任何下限都属于模型参数。
5. 算子需检查对称性、互易性、特征值、条件数、有限性和路径不可逆性。
6. 当前状态下的受损弹性算子不自动等于含损伤演化导数的算法一致 `DDSDDE`。

## A2 — 触发与路由

在以下场景调用：

- 将 `E_L/E_R/E_T/G_LR/G_LT/G_RT` 分别乘退化系数，却没有处理泊松耦合。
- 多个损伤模式按代码循环覆盖同一刚度项，结果依赖模式顺序。
- 损伤增大后矩阵非对称、非正定、条件数爆炸或出现负刚度。
- 材料轴旋转后剪切槽和损伤方向不一致。
- 用户把 `C(d)` 直接作为完整 `DDSDDE`，没有考虑活动损伤导数。

若问题只是 Voigt/旋转表示，转 `abaqus-tensor-voigt-adapter`；若损伤历史或同时提交错误，转 `wood-cdm-multimode-state-machine`。

## 输入与输出合同

必需输入：健康材料柔度/刚度、材料轴、损伤变量定义、模式到算子项的映射、组合规则、残余刚度/删除策略和 Abaqus 应力应变排列。

输出：

- 健康与受损六维算子的逐项定义。
- 模式—算子影响矩阵与组合顺序。
- 对称性、互易性、正定/半正定、条件数和极限状态检查。
- 与 Voigt、方向场、状态机和 `DDSDDE` 的接口合同。
- `OPERATOR_CLOSURE_PASS`、`PASS_WITH_LIMITS` 或 `FAIL`。

## E — 执行步骤

1. 冻结 Abaqus 分量排列、工程剪切约定和积分点 L/R/T 材料轴。
2. 从健康参数构造完整六维柔度或刚度，并检查泊松互易和正定性。
3. 建立每个 `d_i` 对法向、剪切与耦合项的显式影响表。
4. 选择在柔度域、刚度域或能量势中退化，并说明该选择如何保持对称和耗散一致。
5. 定义多模式组合与 `d -> 1` 极限；残余刚度、上限或删除阈值必须显式登记。
6. 对单模式、双模式、全模式和损伤排列置换做特征值、条件数和应力响应测试。
7. 将材料轴算子交 `abaqus-tensor-voigt-adapter` 做旋转和剪切槽验证。
8. 若损伤在增量内活动，将完整更新交 `ddsdde-finite-difference-audit`，区分状态算子与算法切线。

## B — 边界

- 只退化对角弹性模量不能保证耦合项物理一致。
- 任意残余刚度可能控制峰后耗散和失效时间，不能只作为求解技巧隐藏。
- 正定性通过不证明损伤演化热力学闭合；仍需 `wood-cdm-thermodynamic-closure`。
- 材料坐标下正确的矩阵可能在错误 Voigt/旋转映射后失效。
- 本 skill 不选择损伤起始准则、演化律或塑性积分器。
