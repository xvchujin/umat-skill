# Abaqus 张量、Voigt 与材料坐标适配

## I — 方法论骨架（Interpretation）

1. 先把宿主接口表示、历史槽表示、理论 Voigt 记号和材料坐标分成四层；不要把任一一维数组直接 `reshape` 成张量。
2. 用子程序类型、目标版本、单元运动学与 `NDI/NSHR/NTENS` 决定有效分量；不要用“`NTENS=4` 就是某种二维问题”的猜测代替接口表。
3. 为应力、总/增量应变、每套 STATEV 张量和切线分别声明顺序、基底与剪切尺度；不要让相同的 `1:6` 外形掩盖不同语义。
4. 对 Abaqus/Standard UMAT 的应变入口执行 `γij→εij=γij/2`，对应力剪切不缩放；对 VUMAT 按目标版本的张量剪切契约处理。
5. 在张量内积、J2 范数、塑性功和四阶切线中从功共轭定义恢复剪切权重；不要用普通六维欧氏内积猜系数。
6. 把 Hill48 的 `F,G,H,L,M,N` 和方向强度比固定在材料 1/2/3 轴；先旋转到材料轴再评价，返回时同步变换应力、切线和张量历史。
7. 把 J2 legacy 13 槽历史与 8 槽 F90 历史视为不同表示版本：前者的应变历史使用 Abaqus 工程剪切，后者的塑性历史使用张量剪切。
8. 对 Tsai-Wu 明确区分物理剪切方向、Abaqus 槽位和理论系数名称；不要按 `F44/F55/F66` 的数字标签直接对号。
9. 按显式置换而非“左上角”假设压回 `DDSDDE`；只有内部/宿主顺序完全相同且运动学允许时才可裁剪。
10. 用基向量、正负纯剪、往返、功共轭、0°/90°/45°材料轴和旋转历史测试关闭表示链；不要用最终云图代替这些断言。

### 证据化表示表：只作为已识别实现的映射，不作为全局默认

| 对象 | 物理顺序/含义 | 精确表示事实 | 适配动作 |
|---|---|---|---|
| 3D Standard UMAT | `11,22,33,12,13,23` | 应变剪切槽为 `γ12,γ13,γ23`；应力剪切不乘/除 2 | unpack 应变时除 2，pack 时乘 2 |
| Hill48 | `2Lσ23², 2Mσ31², 2Nσ12²` | `L/M/N` 分别属于材料轴 `23/31(13)/12` | 材料轴评价后映射到宿主槽 `6/5/4` |
| J2 legacy 13 槽 | `STATEV(1:6)=εe`，`7:12=εp`，`13=epbar` | 两组六分量应变历史采用 Abaqus 工程剪切语义 | 旋转前先恢复为张量剪切，写回时恢复工程剪切 |
| J2 F90 8 槽 | `1=epbar`，`2:7=εp(11,22,33,12,13,23)`，`8=Dp` | `STATEV(2:7)` 的剪切历史是张量剪切 | 不再除 2；禁止按 13 槽约定解释 |
| Tsai-Wu 准代码 | Abaqus 槽 `4/5/6 = 12/13/23` | 代码名称为 `F66/S12`、`F44/S13`、`F55/S23` | 建立 `物理方向↔槽位↔系数名` 三列表，不按编号猜 |

## A2 — 触发场景（Future Trigger）★

### 用户会在什么情境下需要这个 skill？

1. 同一 UMAT 要支持三维、平面应变或轴对称接口，`NTENS=4/6` 路径表现不一致。
2. 正向拉伸结果正确，但纯剪响应、`J2` 或能量恰好差 2 倍或 1/2。
3. 理论文献、Abaqus 数组和自定义 SDV 对 12/13/23 剪切分量使用不同编号。
4. 正交复材、铺层或部件旋转后，方向强度和损伤云图随全局坐标异常变化。
5. 需要把内部四阶切线安全压回 `DDSDDE(4×4/6×6)`。
6. 两套 J2 都有六分量塑性应变历史，却在纯剪或 restart 后恰好差 2 倍。
7. Hill48 在 0° 正确、45°/90° 错误，怀疑 Orientation、重复旋转或 `L/M/N` 剪切方向错接。

### 语言信号（用户的话里出现这些就应激活）

- “Voigt to tensor / tensor to Voigt 怎么写？”
- “engineering shear factor 2 到底放哪？”
- “NTENS=4 正常，NTENS=6 不正常。”
- “材料 1 方向和全局 X 方向不一致。”
- “纯剪结果差一倍 / wrong shear slot / rotated ply”。
- “J2 13-state engineering shear vs 8-state tensor shear.”
- “Hill48 L/M/N map to which Abaqus slots?”
- “Tsai-Wu F44/F55/F66 labels do not match 12/13/23.”

### 与相邻 skill 的区分

- 与 I03“PROPS/STATEV 位置契约”的区别：I03 管材料参数和历史槽位；本 skill 管应力、应变、切线和材料坐标的表示转换。
- 与 I01“机制路由”的区别：本 skill 不决定显式、隐式或失效分支，只保证各分支收到相同且正确的张量语义。
- 与 I10“DDSDDE 扰动审计”的区别：本 skill 构造维数/基底/剪切适配；I10 从完整更新映射数值验证最终 Jacobian。
- 与 I14“Tsai-Wu 参数与材料坐标审计”的区别：题目只要求材料轴、剪切槽位、工程因子或往返映射时，本 skill 是唯一当前入口，即使问题由失效 SDV 暴露；只有同时审计方向强度、`Fij`、参数来源或 `e` 阈值时，I14 才主责并组合本 skill。
- 与 J2/STATEV 迁移契约的区别：本 skill 只证明 13 槽与 8 槽的剪切表示如何转换；是否允许 restart、如何补齐缺失历史由 `umat-props-statev-contract` 决定。
- 与 `hill48-yield-calibration-applicability-audit` 的区别：本 skill 固定材料轴、旋转与剪切表示；后者审计 Hill48 参数语言、标定覆盖和模型可表达性。两类问题同时出现时组合调用。

## E — 可执行步骤（Execution）

当 skill 被激活后，agent 应按以下步骤执行：

1. **冻结接口与运动学契约**
   - 记录子程序类型（UMAT/VUMAT）、Abaqus 版本、单元族、`NDI/NSHR/NTENS`、数组次序、平面应变/平面应力/轴对称条件和材料方向定义。
   - 完成标准：能逐槽写出输入应力、输入应变和 `DDSDDE` 的基底；没有“通常是 4/5/6”式猜测。
   - 判停条件：若接口类型、单元运动学或目标版本不明，停止编码并先查目标 Abaqus 版本官方手册；在证据到位前不得假定 `NTENS=4` 就是平面应力，也不得冻结四槽顺序。

2. **定义唯一规范内部表示**
   - 选择完整 `3×3` 对称张量及明确的四阶/矩阵基底；为全局坐标、材料坐标以及每套历史 ABI 分别命名。
   - 完成标准：一张表同时给出张量分量、内部索引、Abaqus 槽位、理论 Voigt 编号、应力/应变类型和剪切尺度；Hill48、J2 历史与 Tsai-Wu 均能落表。

3. **分别实现应力与应变的入口适配**
- 按 `NTENS` 读取有效槽位；在目标实现明确声明的四分量路径中按明示顺序补齐内部六分量。为 UMAT 应变、VUMAT 应变、13 槽历史和 8 槽历史调用各自的有类型 pack/unpack；不要用一个无模式函数处理全部对象。
   - 完成标准：每个合法接口/历史版本的单位基向量逐一往返后回到原槽位和原数值；13 槽与 8 槽纯剪在转换到同一张量后相等；二维路径不访问第 5、6 接口槽。
   - 判停条件：平面应力若尚未求解厚度方向约束，不能用简单补零继续。

4. **进入材料坐标并执行核心本构**
   - 对各向异性材料只旋转一次，把应力、应变和必要历史张量送到材料 1/2/3 轴；在该坐标中让 Hill48 `F…N/Rij`、Tsai-Wu 强度和方向状态使用同一轴定义。
   - 完成标准：记录旋转发生在宿主、适配层还是核心；同一物理铺层随部件刚体转向后材料响应保持一致，0°↔90° 交换只交换预期方向。
   - 判停条件：若方向矩阵、铺层定义或状态张量旋转规则缺失，停止解释方向强度/SDV。

5. **变换切线并压回宿主表示**
   - 将更新后的应力和切线变回宿主坐标，显式处理应力/应变基底缩放；按实际槽位置换和 `NTENS` 返回 4×4 或 6×6。
   - 完成标准：`DDSDDE` 的每一列都对应宿主 `DSTRAN` 的同一工程分量；不能只验证矩阵尺寸。

6. **执行四类最小核验**
   - 往返：每个基分量 pack→unpack；纯剪：分别检查 UMAT、VUMAT、J2 13/8 槽因子；能量：验证 `σ:ε`/功共轭；方向：用 0°/45°/90° 检查 Hill48 与方向 SDV；置换：独立激活 Tsai-Wu 的 12/13/23 通道。
   - 完成标准：误差阈值事先定义，所有用例在阈值内；`L/M/N`、`F66/F44/F55` 和 13/8 槽剪切逐项命中预期物理方向。任一错位即回到步骤 2，不在本构公式中补经验系数。

## B — 边界（Boundary）★

### 不要在以下情况使用此 skill

- 只需建立 PROPS/STATEV/SDV 的参数和历史下标表时；使用 I03。
- 只需选择 α、Δλ 或 e 的算法分支时；使用 I01。
- 想用小应变 Voigt 适配代替有限应变、客观应力率或旋转历史量更新时。
- 需要决定 13 槽 restart 是否能迁移到 8 槽、补齐 `Dp` 或弹性应变历史时；表示换算不能证明历史可逆迁移。
- 需要标定 Hill48 `F…N/Rij/r` 或核对 Tsai-Wu 强度/交互项时；分别转交参数审计，本 skill 只固定轴、槽和尺度。
