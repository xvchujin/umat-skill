# 木材 CDM 热力学闭包审计

## I — 方法论骨架

1. 先声明自由能与状态变量，再从自由能导出应力和损伤驱动力。
2. 区分名义应力、有效应力、弹性应变、塑性应变和损伤变量，禁止同一符号跨角色漂移。
3. 每个损伤模式都需要明确的驱动力、历史变量、加载函数和不可逆条件。
4. 损伤起始、演化、卸载和再加载必须属于同一个离散状态更新，不得只给连续公式。
5. 耗散必须非负；数值稳定项和物理耗散应分开报告。
6. 热力学闭包不等于算法切线闭包，`DDSDDE` 仍要对完整离散映射做有限差分审计。

## A2 — 触发与路由

在以下场景调用：

- 代码只有 `FI >= 1` 与经验退化因子，却没有自由能或驱动力定义。
- 多个 L/R/T 与剪切损伤变量被直接乘到刚度上，卸载路径含义不清。
- 用户无法说明 `d` 的历史变量、Kuhn–Tucker 条件、耗散符号或再加载规则。
- 塑性与损伤耦合后，不知道应力功如何分配到塑性耗散与损伤耗散。

若还没决定永久变形、刚度退化和裂纹分别由谁承担，先转 `wood-cdm-mechanism-router`。若自由能已冻结，只剩六维算子正定性，转 `wood-cdm-damaged-operator-closure`。

## 输入与输出合同

必需输入：自由能候选、应力与应变度量、损伤/塑性状态变量、起始与演化函数、卸载规则、能量输出和积分点材料轴。

输出：

- 状态变量和共轭力表。
- 自由能、应力、损伤驱动力和耗散不等式的闭包。
- 每个模式的加载函数、历史变量和不可逆条件。
- 离散更新顺序、失败回滚要求及未闭合项。
- `THERMODYNAMIC_CLOSURE_PASS`、`PASS_WITH_ASSUMPTIONS` 或 `FAIL`。

## E — 执行步骤

1. 冻结小应变/有限应变框架、材料轴和应力应变度量，避免混用不同功共轭对。
2. 列出弹性、塑性、损伤和温湿耦合状态变量，标明可恢复与不可恢复部分。
3. 写出自由能 `Psi(state)`，从中导出应力及每个损伤变量的驱动力 `Y_i = -dPsi/dd_i`。
4. 为每个模式定义加载函数、历史变量、互补条件和 `d_i` 上下界。
5. 检查总耗散、塑性耗散、损伤耗散和人工黏性耗散的符号与输出通道。
6. 定义加载、卸载、再加载和模式同时激活时的离散更新顺序。
7. 用单调、卸载—再加载、循环和双模式路径检查不可逆性与能量闭包。
8. 将完整离散更新交 `ddsdde-finite-difference-audit`，不要把当前受损弹性矩阵冒充一致切线。

## B — 边界

- 失效指标只提供起始信息，不能自动生成自由能或演化律。
- `d` 单调增加不自动证明耗散非负；必须检查它的共轭驱动力和离散功。
- 人工黏性可改善收敛，但必须与材料耗散分列，不能作为热力学闭包的替代证据。
- 仅凭 ODB、云图或作业完成不能证明能量闭包。
- 本 skill 不确定强度参数，也不推导专用塑性回映。

## 相关 skills
