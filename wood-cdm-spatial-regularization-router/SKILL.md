# 木材 CDM 空间正则化路由器

## I — 方法论骨架

1. 局部应变软化缺少空间长度时会趋向零宽局部化；网格依赖首先是构成问题，不只是求解器噪声。
2. 先确认确有软化和局部化，再判断是否存在单一主导模式、可信裂纹法向和特征长度。
3. 裂带法用方向断裂能与单元尺度 `h/CELENT` 做能量尺度化，前提不满足时不能声称客观。
4. 积分非局部或梯度增强通过邻域或附加场引入构成内长度，适合模式竞争、路径和带宽需要空间控制的场景。
5. 人工黏性引入时间尺度，可以帮助收敛，但不提供空间内长度。
6. 多网格验收必须同时比较峰值、完整峰后、耗散、物理带宽、裂纹路径和模式。
7. 残余刚度、断裂能、内长度和黏度的改动都属于可追踪模型变更。

## A2 — 触发与路由

在以下场景调用：

- 木材 UMAT 进入峰后后网格越细越脆、耗散下降或形成单元素损伤带。
- 已使用 `CELENT` 或断裂能，峰值接近但峰后、带宽或裂纹路径仍漂移。
- 不知道应选裂带、积分非局部、梯度损伤还是黏性稳定。
- 混合模式无法定义唯一裂纹方向或特征长度。
- 内长度、演化参数与网格尺寸存在强补偿，需要可证伪标定矩阵。

机制尚未冻结时先用 `wood-cdm-mechanism-router`。选定非局部或梯度路线后，用 `wood-cdm-abaqus-nonlocal-architecture-router` 检查求解器载体。

## 输入与输出合同

必需输入：局部本构曲线、材料轴和活动模式、局部化拓扑、方向断裂能、网格尺寸/方向、候选 `h` 或 `l_c`、求解器预算、DIC/裂纹与能量证据。

输出：

- `NO_SOFTENING_GATE`、`CRACK_BAND`、`INTEGRAL_NONLOCAL`、`GRADIENT` 或 `DISCRETE_OTHER` 路由。
- 长度、能量、边界条件和黏性角色清单。
- 至少三网格联合验收矩阵及预设容差。
- `OBJECTIVITY_EVIDENCE_PASS`、`PASS_WITH_LIMITS`、`FAIL` 或 `BLOCKED_BY_MISSING_DATA`。

## E — 执行步骤

1. 指出哪一状态变量导致峰后承载下降及其能量尺度；纯硬化塑性直接返回 `NO_SOFTENING_GATE`。
2. 用物理、试验/DIC 或初步数值场判断局部带、主导模式、裂纹法向和拓扑变化。
3. 单一模式、局部带和方向化 `h` 均可信时可选裂带；模式竞争或有限带宽要求比较非局部与梯度路线。
4. 裂带冻结各模式 `G_f` 与 `h`；非局部/梯度冻结 `l_c`、核或梯度系数、交互函数和边界条件。
5. 将人工黏性、`d_max` 和残余刚度登记为模型变更，单列黏性耗散并做黏度趋零测试。
6. 至少采用三种网格，比较完整峰后、总/损伤/黏性耗散、带宽、跨单元数、路径和模式。
7. 把载荷骤降或删除与局部应力、损伤、畸变、能量和邻域传力对应，排除数值塌陷。
8. 分别报告通过、失败和未测项，保留 `l_c/G_f/黏度` 的标定与敏感性范围。

## B — 边界

- 裂带只在局部化、主导模式和方向尺度前提成立时适用。
- `h/CELENT` 随离散改变，`l_c` 是待标定的构成空间尺度，二者不能混用。
- 黏性提供时间尺度，不提供空间客观性。
- 峰值接近、云图平滑或作业完成均不是独立客观性证据。
- 多网格相近不证明参数唯一；长度与演化参数可能相互补偿。
