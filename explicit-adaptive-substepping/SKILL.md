# 显式 UMAT 的联合状态自适应子步

## I — 方法论骨架 (Interpretation)

自适应子步是在一次 UMAT 全局应变增量内部，用归一化局部路径参数 `T∈[0,1]` 控制积分工作量。
每个候选子步开始前都要保存完整 committed 快照，包括应力、所有演化状态及路径位置。
从同一快照计算低阶和高阶近似；两种近似必须覆盖同一组状态变量，不能只提高应力阶数。
两解之差只是局部截断误差代理 `η_emb`，需用绝对/相对混合尺度归一化，并以所有受控分量中的最坏值验收。
数值误差门与物理约束门相互独立：`η_emb` 合格不代表屈服残差、定义域和有限数合格；`η_emb` 也不是 Tsai-Wu 失效指数 `e`。
只有所有门都通过才原子提交高阶候选并推进 `T`；任何门失败都恢复快照，再缩小局部 `DT` 重算同一段。
步长控制器既要限制增长，也要给出缩小下界、局部步长下限、重试上限和剩余区间截断。
预算耗尽不是“接受最后结果”的理由，而是带着干净旧状态进入全局失败/cutback 协议。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 显式本构积分对固定子步数敏感，精度与速度无法兼顾。
2. 代码已有 Euler/Heun、RK23/RKF23 或两组候选解，却没有可靠 accept/reject 和 rollback。
3. 应力误差合格但硬化、孔隙比、织构或损伤变量随步长明显漂移。
4. 局部子步无限缩小、反复重试，或在最小步长处静默接受坏解。
5. 正在审查 `RTOL`、`XTOLRC`、`CNVERG`、`local DT`、substep controller。

### 语言信号 (用户的话里出现这些就应激活)

- “显式积分怎么自动分子步 / adaptive substepping”
- “embedded Euler / improved Euler / RKF23 error estimate”
- “accept reject rollback / rejected step still changes STATEV”
- “RTOL、XTOLRC、CNVERG 怎么定义”
- “应力收敛但内变量不收敛 / joint-state error norm”

### 与相邻 skill 的区分

- 与 `explicit-alpha-yield-intersection`：后者先定位弹性终点 `α`；本 skill 对剩余 `(1-α)Δε` 分配和验收局部 `DT`。
- 与 `explicit-yield-drift-correction`：本 skill 控制两阶近似差 `η_emb`；后者在候选子步后检查并修复屈服残差。
- 与 `umat-failure-cutback-protocol`：本 skill 优先在 UMAT 内局部重试；后者只在局部预算耗尽或不可恢复失败时请求全局重算。
- 与 `umat-transactional-state-update`：本 skill 必须同时出现嵌入误差估计、local `DT` 和接受/拒绝控制；若只需修复 trial/committed 状态污染，使用事务式状态技能。
- 与隐式 return mapping：本 skill 的 `DT` 控制显式路径离散，不负责求解一致性乘子 `Δλ`。

## E — 可执行步骤 (Execution)

1. **定义联合状态、尺度和配置**
   - 列出应力与所有演化状态 `y=[σ,q]`，为每一类量给出 `atol_i+rtol_i·scale_i`，并参数化安全系数、增长/缩小限幅、`DT_min`、重试和总子步预算。
   - 完成标准：没有演化变量被排除于误差控制；无量纲误差在分量过零时仍有限，参数的单位依赖被记录。
   - 判停路径：若关键状态无可辩护尺度或存在未初始化分量，停止配置，不能用单个裸相对误差继续。

2. **建立归一化局部路径**
   - 把待积分的剩余应变映射到 `T∈[0,1]`，初始化 `T=0`，并令 `DT` 不超过剩余 `1-T`。
   - 完成标准：每个接受子步的局部增量之和最终精确覆盖剩余路径，无超调、重复或漏积分。

3. **对子步起点做完整快照**
   - 保存应力、全部状态变量、能量/辅助输出、`T` 以及控制器所需历史；候选计算只写 trial 缓冲区。
   - 完成标准：执行任意次数拒绝后，逐分量比较都能恢复到相同起点。

4. **从同一起点计算嵌入解对**
   - 形成低阶候选 `y_L` 和高阶候选 `y_H`；每次斜率评价使用对应的完整候选状态，所有内部变量与应力采用设计要求的同阶公式。
   - 完成标准：两解覆盖同一物理时间段和同一状态向量，独立常步长收敛试验显示预期阶次。
   - 判停路径：导数、候选状态或尺度出现 NaN/Inf、越过模型定义域时，拒绝本子步；若缩步后重复出现则进入失败升级。

5. **计算最坏分量误差 `η_emb`**
   - 对每个受控分量计算尺度化 `|y_H-y_L|/(atol_i+rtol_i·scale_i)`，用最大值或明确的保守范数组合；另保留各分量诊断。
   - 完成标准：人为放大任一状态误差都会使总 `η_emb` 不减；复核 `CNVERG` 不存在“小误差覆盖大误差”，`FDIFTL` 等受控量没有遗漏。

6. **执行独立的数值门和物理门**
   - 数值门要求 `η_emb≤1`（或等价明确阈值）；物理门检查有限数、可容许域、屈服残差和模型不变量，必要时调用漂移修正后重新验收。
   - 完成标准：每个门有独立布尔结果和失败原因；漂移修正后的状态仍需重新通过全部相关门。

7. **接受：原子提交并调下一步**
   - 仅在所有门通过后提交 `y_H`，推进 `T←T+DT`，按嵌入阶数和 `η_emb` 计算下一 `DT`，施加增长上限并截到剩余区间。
   - 完成标准：一次提交包含应力和所有状态；`T` 单调且最终在容差内到达 1；控制器不会因 `η_emb=0` 产生除零或无界放大。

8. **拒绝：回滚并重算同一段**
   - 丢弃全部 trial 输出，从快照恢复，按安全系数缩小局部 `DT`，增加拒绝计数但不推进 `T`。
   - 完成标准：失败子步对已提交材料历史的净影响严格为零；新 `DT` 有限、为正且小于旧值。
   - 判停路径：`DT≤DT_min`、重试/总子步预算耗尽、控制器停滞，或同一不可恢复域错误重复出现时，停止局部循环并交给 `umat-failure-cutback-protocol`。

9. **结束与独立精度核验**
   - 到达 `T=1` 后返回联合状态及诊断；用至少两档容差和高精度参考路径检查误差随容差收紧而下降。
   - 完成标准：结果不依赖任意初始子步，且接受/拒绝数量、最坏误差分量、最小 `DT` 可追踪。

## B — 边界 (Boundary)

### 五个控制量必须隔离

- `α`：总增量中先走完的弹性路径比例；它只决定子步器接收多少剩余应变，不是子步大小。
- 局部 `DT`：归一化局部路径 `T` 的一次推进量；它是 UMAT 内部变量，不等于 Abaqus 的全局 `DTIME`。
- `Δλ`：塑性流动/一致性方程的乘子；显式子步可以更新它所代表的塑性演化，但 `DT` 不是 `Δλ`。
- `PNEWDT`：返回给 Abaqus 的全局增量比例建议；局部拒绝应先调整局部 `DT`，不应每次都改 `PNEWDT`。
- `η_emb`：嵌入解对差异构成的局部误差代理；它不是真实误差，不等于屈服漂移残差 `f`，也不等于 Tsai-Wu 失效指数 `e`。

### 不要在以下情况使用此 skill

- 唯一任务是找弹性路径首次屈服点：使用 α 交点 skill。
- 候选解局部误差合格但偏离屈服面：使用漂移修正，并保留本 skill 的验收门。
- Abaqus 全局 Newton 或接触失败且材料点局部积分均正常：应查全局模型，而非继续缩局部 `DT`。
- 需要证明严格真实误差界：嵌入解差只能提供估计，需更高精度参考或理论分析。

## 相关 skills

- **depends-on**: `umat-transactional-state-update`——拒绝子步必须从完整 committed 快照重算，不能只恢复应力。
- **contrasts-with**: 无——显式/隐式路线的唯一二选一边已在入口层表达，本 skill 不另建重复对比边。
