# Tsai-Wu 判据参数、单位与材料坐标审计

## I — 方法论骨架 (Interpretation)

Tsai-Wu 判据先回答“材料坐标中的组合应力是否到达强度包络”，不回答后峰如何退化。
可靠实现从参数契约开始：每个模量、泊松比、拉压强度、剪切强度和交互项都要绑定方向、单位、符号与来源。
全局应力必须先变换到材料 1/2/3 轴，再按实现实际使用的 Voigt 次序进入公式。
理论文献和 Abaqus 的剪切槽位可能采用不同顺序；相同下标不代表相同平面。
系数和分支先用零应力、单轴拉压、纯剪及简单组合态验证，再接复杂模型。
若文字说明与实现中的不等号存在矛盾，安全域和触发域必须由测试固定。
只有这套前置契约通过，失效指数 `e` 才有可解释性。
当前源码把 23 项精确限定为 9 个弹性常数、9 个正幅值强度和 5 个 beta；任何短数组、负压缩强度或零强度都必须在计算前拒绝。
`Phi` 与六槽 `e` 不是同义量：代码只写一个 `e(IMAX)`，若不先把全部六槽清零，后续 `maxval`、损伤和删除会读取未定义值。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 从论文或材料手册把 Tsai-Wu 强度参数写入 UMAT/材料卡。
2. 计算出的 `e` 数值看似合理，但旋转铺层、纯剪或拉压方向结果异常。
3. `PROPS` 数量、顺序、单位或拉压强度正负约定不清。
4. 需要确认 `e<1`、`e≥1` 的安全/触发分支是否写反。
5. 相同输入在不同编译选项下出现随机损伤/删除，怀疑 `e(1:6)` 未全量初始化。

### 语言信号 (用户的话里出现这些就应激活)

- “Tsai-Wu 的 F12/Fij 怎么填 / interaction coefficient”
- “23 个 PROPS 顺序是什么 / parameter mapping”
- “材料轴旋转后失效指数不对，同时要核强度/Fij/23-PROPS / material orientation plus strength contract”
- “0° 的 e 正常，45° 或纯剪的 e 不对，并怀疑方向强度或交互项映射”
- “e 到底大于还是小于 1 失效 / trigger inequality”
- “为什么只改 σ2 会改变 3 向压缩损伤 / wrong stress slot”
- “maxval(e) 随编译器变化 / uninitialized failure buffer”

### 与相邻 skill 的区分

- 与 `abaqus-tensor-voigt-adapter` 的区别：只排材料轴、12/13/23 槽位、工程剪切因子 2 或往返映射时，由 adapter 唯一主责，即使故障经 Tsai-Wu `e`/SDV 暴露；一旦同时涉及方向强度、`Fij`、23-PROPS 或 `Phi/e` 阈值，本 skill 主责并组合 adapter。
- 因而“旋转后 `e` 错，只想查轴/槽/因子 2”是本 skill 的负触发；“旋转后 `e` 错，还要审强度、`Fij`、阈值或 23-PROPS”才由本 skill 主责。
- 与 `tsai-wu-damage-state-machine` 的区别：本 skill 只判定失效起始 `e`；后者处理归因、退化和历史提交。
- 与 `umat-props-statev-contract` 的区别：后者建立通用位置数组契约；本 skill 审核 Tsai-Wu 特有的强度、交互项和方向测试。
- 与 `umat-update-mechanism-router` 的分工：机制尚未确定时由路由器先把 `e` 送入失效支路；进入 Tsai-Wu 后，本 skill 才固定参数与失效起始。

## E — 可执行步骤 (Execution)

1. **建立可追溯参数表**
   - 固定 23 槽：`E11,E22,E33,nu12,nu13,nu23,G12,G13,G23,Xt,Xc,Yt,Yc,Zt,Zc,S12,S13,S23,beta_ft,beta_fc,beta_mt,beta_mc,beta_s`。
   - 把拉压强度写成正幅值，记录方向、单位、来源、允许域与交互项是假设还是双轴标定。
   - 完成标准：`NPROPS>=23`；模量/强度有限且为正；beta 域和正交弹性稳定性有明确守卫；无死输入被误称为有效参数。

2. **固定材料坐标与分量置换**
   - 明确全局→材料轴旋转，并写出理论次序与 Abaqus `11,22,33,12,13,23` 的置换表。
   - 完成标准：三个法向与三个纯剪往返测试分别命中预期方向，旋转试样不改变材料局部定义。

3. **独立计算系数与失效指数**
   - 每次先令 `e(1:6)=0`，再统一单位、按拉压非对称强度和交互项来源构造系数；分别保存标量 `Phi`、贡献通道 `Xphi` 和归因缓冲 `e`。
   - 完成标准：零应力时所有槽有限且确定；六个单分量与组合态同手算/独立脚本一致；重复调用不保留旧 `e`。

4. **锁定触发约定**
   - 明确安全域、边界和触发域；对 `e=0`、`1±ε` 及明显超阈值状态做分支测试。
   - 判停条件：若口述、课件和实际代码不等号不能统一，停止损伤接入并要求取得源码或明确模型定义。
   - 增加 3 向压缩专项：固定 `σ3<0` 并独立改变 `σ2`，结果不得由 `σ2` 切换模式。
   - 完成标准：初始无应力不会损伤，超阈值必定触发，阈值两侧可复现，3 向符号只由 `STRESS(3)` 决定。

5. **输出审计报告而非猜测参数**
   - 列出已证参数、待标定参数、缺失源码项和每个单测结果。
   - 完成标准：任何未知的交互项或 23 项位置都被显式标记，未由 agent 擅自补值。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 用户要识别纤维/基体、拉/压等显式失效模式：Tsai-Wu 标量判据本身不提供这些模式。
- 用户已经进入后峰刚度折减或断裂能标定：应调用损伤状态机与软化客观性审计。
- 用户处理塑性屈服一致性：`e` 不是 `F` 的塑性残差，也不是 `Δλ`。

## 相关 skills

- **depends-on**: `umat-props-statev-contract`、`abaqus-tensor-voigt-adapter`——必须先锁定强度/交互项槽位、单位、材料轴和剪切次序。
- **contrasts-with**: 无——本 skill 只审计 Tsai-Wu 失效起始参数，不与触发后的损伤演化器竞争。
- **composes-with**: `umat-update-mechanism-router`——机制未定时先路由；进入 Tsai-Wu 支路后由本 skill 固定参数与失效起始。
