# DDSDDE 完整映射有限差分审计

## I — 方法论骨架 (Interpretation)

`DDSDDE` 的审计对象不是某个瞬时本构公式，而是 UMAT 从同一已提交状态出发的完整离散映射。
把一次调用抽象为 `M:(σ_n,q_n,Δε)→(σ_{n+1},q_{n+1})`，目标 Jacobian 是该算法输出应力对本次应变增量的局部导数。
因此每个扰动样本都必须恢复同一 committed 快照，并完整重跑分支、交点、子步、回映、损伤与提交逻辑。
光滑活动集内优先用中心差分；扰动跨越屈服或损伤触发面时，改用单边/分段结果并报告不可微性。
扰动量需要随应变尺度调整并做多档收敛检查，避免截断误差和舍入误差各自伪造通过。
比较不只看矩阵逐项，还要看列范数、应力预测误差、分量次序和工程剪应变约定。
路径加权刚度、塑性分支的 `De`、当前退化弹性矩阵都可以是教学或工程近似，但只有通过完整映射审计后才能量化其适用性。
先把基准点标成 J2 弹性、J2 塑性且位于单一硬化段、硬化表拐点、损伤阈值前后或已损伤固定活动集；不同类别不得共享一个“中心差分必须通过”的结论。
对 J2 弹性基准，验证 `De` 的确是完整映射导数；对 J2 塑性基准，拒绝用弹性区通过替塑性 `DDSDDE=De` 借证。
对 Tsai-Wu，分别审计“冻结 dmg 的当前刚度”这一近似声明和“允许激活/演化的完整映射”；只有后者能评价算法一致 Jacobian，阈值上则只报告方向导数或不可微。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. UMAT 的应力/状态看似合理，但全局 Newton 比内置模型明显慢或频繁 cutback。
2. 用户声称返回了“consistent tangent”，却只有状态点切线、路径加权矩阵或退化弹性矩阵。
3. 塑性屈服、损伤起始或状态变量演化后，`DDSDDE` 与数值响应不匹配。
4. 修改 Voigt 次序、工程剪切或二维/三维映射后，需要验证 Jacobian 列的物理含义。
5. J2 弹性分支的 `De` 能通过，但塑性后全局 Newton 明显变慢，需要防止用弹性测试替塑性切线借证。
6. 扰动跨越硬化表节点、`Phi=1` 损伤阈值、删除阈值或模式归因 tie，中心差分结果随 `h` 跳变。
7. 需要区分“冻结状态条件刚度”与“完整 switching/evolution map Jacobian”。

### 语言信号 (用户的话里出现这些就应激活)

- “帮我做 DDSDDE finite-difference check”
- “consistent tangent 怎么验证 / verify Jacobian”
- “为什么应力对但 Newton convergence 很差？”
- “扰动应变后数值导数和 DDSDDE 不一致”
- “损伤触发点的 tangent 应该怎么算？”
- “plastic branch still returns elastic De”
- “frozen damage tangent / hardening-table kink active set”

### 与相邻 skill 的区分

- 与 `j2-isotropic-hardening-radial-return` 的区别：后者构造并收敛三维小应变关联 J2 的应力—状态更新；本 skill 在该更新已通过状态审计后，验证其塑性分支返回的完整 Jacobian，而不是只验证弹性 `De`。
- 与 `cpa-implicit-return-mapping` 的区别：CPA skill 负责使局部塑性状态满足一致性；本 skill 只审计该完整更新器返回的导数。
- 与 `umat-transactional-state-update` 的区别：后者保证每个扰动从同一 committed 快照起步；本 skill 在此前提上构造有限差分列。
- 与 `explicit-adaptive-substepping` 和 `tsai-wu-damage-state-machine` 的分工：两者分别提供显式路径与损伤状态更新，本 skill 只审计它们完成后的完整离散映射 Jacobian。
- 与 `umat-hierarchical-validation` 的区别：本 skill 是验证矩阵中的专项数值门；后者组织算子、材料点、单元体和边值问题的整条证据链。
- 与 `umat-semantic-debugging` 的区别：本 skill 发现导数不一致及其分量模式；后者沿数据流定位漏赋、旧状态或实参角色错误。

## E — 可执行步骤 (Execution)

1. **冻结审计基准与调用契约**
   - 保存完整 committed 输入：`STRESS_n`、全部 `STATEV_n`、`DSTRAN`、材料参数、时间/温度/场变量、方向和维数信息。
   - 运行一次未扰动更新，记录 `σ_0`、`q_0`、`DDSDDE_0`、活动分支、硬化表区间/端点、损伤通道、删除/事件、局部迭代数和 cutback/失败码。
   - 完成标准：任意扰动试验都能从逐位相同的 committed 快照重放，基准运行本身成功且可复现。

2. **设计带尺度的扰动阶梯**
   - 对每个 Abaqus 应变槽 `j` 选多档 `h_j`，同时参考本次增量、代表性应变尺度和机器精度；保留工程剪应变的接口定义。
   - 至少使用三档递减扰动，并事先声明绝对/相对误差指标和活动集保持条件，不采用跨模型固定 `h` 或固定容差。
   - 至少布置五类基准中的适用项：J2 弹性、J2 光滑塑性、硬化表拐点、损伤阈值、阈值后的固定活动集；不得只在最容易通过的弹性点验收塑性/损伤切线。
   - 完成标准：扰动既能产生高于舍入噪声的应力变化，又能观察差分结果随 `h` 的稳定区间；每个模型声明覆盖了哪些基准类、缺哪些类。

3. **从同一快照完整重跑正负扰动**
   - 对每列分别运行 `M(Δε+h_j e_j)` 与 `M(Δε−h_j e_j)`；每次都重新执行 `α` 交点、显式子步、CPA、状态更新、损伤触发和提交。
   - 禁止在一次扰动运行后沿用已修改的 `STATEV`；同时记录两侧弹塑分支、硬化区间、损伤/删除活动集、事件标志与是否正常返回。
   - 审计算法一致切线时允许损伤和硬化逻辑自然重跑；只有明确审计 frozen-damage 条件刚度时才人为固定 `dmg`，并把该结果单独命名，禁止替代完整映射结果。
   - 完成标准：每个差分样本都有独立输入快照、应力输出和活动集标签；失败样本不被静默替换为旧应力。
   - 失败路径：若两侧均失败，先缩小扰动并检查基准离失败边界的距离；仍失败则报告该方向不可审计，而不是伪造一列导数。

4. **按光滑性构造数值 Jacobian**
   - 先建立逐列分类表，枚举且只使用五类结果：中心差分、左单边、右单边、不可微、运行失败；任何缺少正/负样本或无法正常返回的列都必须保留为运行失败，不能从旧应力补列。
   - 两侧活动集相同且响应光滑时，用中心差分 `J_FD(:,j)=[σ(+h)−σ(−h)]/(2h_j)`。
   - 若扰动跨越屈服、硬化表区间、损伤/删除或模式归因事件，分别计算单边导数并标注左/右活动集；若导数不存在，不合并成“唯一真值”。
   - 完成标准：每一列恰有一个上述分类并保留正/负活动集、返回状态和所用 `h` 证据；报告汇总各类列数，零遗漏。

5. **比较矩阵与增量预测能力**
   - 计算逐列/整体绝对误差、相对范数误差和 `DDSDDE_0·δΔε` 对真实 `δσ` 的预测误差；分别检查法向、剪切和耦合块。
   - 对多档 `h` 画出或列出误差变化；只有出现稳定平台或合理收敛趋势，才采用其中最可信区间判定。
   - 对 J2 分开报告弹性与塑性列；对表格硬化分开报告段内与节点左右；对 Tsai-Wu 分开报告 frozen-damage 条件矩阵与完整演化映射。
   - 同时记录各候选切线下的全局 Newton 迭代、cutback 次数和额外局部成本；切线误差与求解器代价必须分栏，不用“更快”替代导数正确性。
   - 完成标准：预设的尺度化门槛有明确通过/失败结论，能定位到具体列、分量和活动集；报告还包含全局迭代/cutback 代价及“严格一致、近似、不可微或运行失败”的限域结论。

6. **分类修复并重新审计**
   - 光滑区系统偏差通常指向漏掉状态演化导数、错误切线、Voigt/剪切映射或返回漏赋；先由本审计把偏差定位到类别，只有确认表示/槽位错误后才把 `abaqus-tensor-voigt-adapter` 列为后续修复，不在诊断前并行抢调用。
   - 仅当 J2 基准确属弹性映射时接受 `De` 为严格导数；塑性 `De`、路径加权矩阵或当前退化矩阵一律按证据标为近似，并记录其误差与全局迭代代价。
   - 对硬化节点或损伤阈值保留左右活动集结论，不为追求单一矩阵而平滑模型；若决定正则化，另行记录为模型变更。
   - 修复后从步骤 1 全量重跑。
   - 完成标准：报告包含基准、扰动阶梯、活动集、误差表、失败路径和“严格一致/近似/不可微”的限域结论。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 局部更新器本身不守恒、残差不收敛或状态提交错误：先修复材料更新，不要让切线审计替代本构正确性。
- 只想验证材料参数、实验拟合或失效模式物理性：有限差分只能检验导数契约。
- 在已知活动集切换点要求一个跨两侧都成立的唯一 Jacobian：非光滑映射可能没有这种导数。

## 相关 skills

- **depends-on**: `umat-transactional-state-update`——所有扰动必须从逐位相同的 committed 状态出发。
- **contrasts-with**: 无——这是完整更新映射的专项导数审计，不替代任一应力更新器或通用验证框架。
- **composes-with**: `explicit-adaptive-substepping`、`cpa-implicit-return-mapping`、`j2-isotropic-hardening-radial-return`、`tsai-wu-damage-state-machine`、`umat-hierarchical-validation`——检查显式、一般 CPA、J2 径向返回和 Tsai-Wu 损伤路线的切线，并把专项结果纳入分层验证。
