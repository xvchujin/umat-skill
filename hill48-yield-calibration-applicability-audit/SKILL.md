# Hill48 屈服标定与适用性审计

## I — 方法论骨架 (Interpretation)

把 Hill48 当作材料轴下的方向屈服几何，不要把它与硬化尺度演化混成一个参数问题。

先审实验角向曲线的峰谷数量、次序和单调性，再决定是否允许任何参数拟合。

把 `F…N`、Abaqus 大 `Rij` 和 Lankford 小 `r` 视为三种不同语言，每次转换都声明起点、终点、参考应力和轴系。

仅在正交各向异性、关联流动、明确参考方向和塑性宽/厚应变比定义下，使用 `r0,r45,r90` 路线。

用 AFR 表示屈服函数与塑性势共用一套参数；用 non-AFR 表示两个函数/两套参数，不要把它降格为“更好的拟合选项”。

把材料 1-2-3 轴、Orientation 的所有者、旋转位置、Voigt 顺序和剪切因子纳入标定契约，不要只保存六个数。

把内置 `*POTENTIAL` 、自编更新器、边值模型和后处理结果分为四个证据对象，禁止互相借证。

只在可表达性、参数语义、物理域、轴向回算和证据层级全部闭合后，接受标定结论。

## A2 — 触发场景 (Future Trigger)

### 在以下场景调用

1. 在 `F,G,H,L,M,N`、大 `Rij` 和小 `r` 之间转换，或不确定 `*POTENTIAL` 六个值的真实语义。
2. 用 0°/45°/90° 或更密集的角向试验标定 Hill48，但拟合留下系统性峰谷误差。
3. 屈服应力可拟合而 `r` 值不可拟合，或 AFR 单参数集无法同时照顾两类曲线。
4. 评审材料轴、Orientation、旋转后方向强度，或核对拉深 `*POTENTIAL` 基准的证据范围。
5. 有人宣称内置 Hill48 算例、云图或一组六参数已证明自编 Hill48 UMAT 正确。

### 识别以下中英文信号

- “Hill48 参数怎么标定 / Hill48 parameter calibration”
- “`F,G,H,L,M,N` 能不能直接填 `*POTENTIAL`”
- “`R11…R23` vs `r0,r45,r90`”
- “yield stress fits but r-values do not / model expressibility”
- “AFR or non-associated flow rule (non-AFR)”
- “双谷、多峰、耳高不对、轧制方向/rolling direction”

### 与相邻 skill 分工

- Hill48 参数审计同时涉及材料轴、Voigt 槽位或工程剪切因子 2 时，组合 `abaqus-tensor-voigt-adapter` 锁定表示闭包；若只有表示错位，则由适配器单独主责。
- 尚未决定用 J2、Hill48、Tsai-Wu 或其他机制时，先调用 `umat-update-mechanism-router`。
- 已选 Hill48 且要推导局部残差、流动梯度和切线时，转 `cpa-implicit-return-mapping`；不要从本 skill 虚构完整更新器。
- 只审计复杂边值模型的证据链时，转 `umat-hierarchical-validation`；本 skill 只标注内置基准能支持什么。
- 目标是三维小应变关联 J2 标量硬化时，转 `j2-isotropic-hardening-radial-return`。

## E — 可执行步骤 (Execution)

1. **锁定对象和证据身份**
   - 标明对象是理论/标定、Abaqus 内置 `*POTENTIAL`、待审用户实现，还是边值结果。
- 若用户只提供 INP、演示文档或云图，立即排除“已获得 Hill48 UMAT/VUMAT”。
   - **完成标准**：输出来源—对象—可支持命题表，且每个结论只引用同一证据对象。

2. **声明材料轴和试验口径**
   - 逐项记录 1-2-3 轴、轧制/横向/厚向、试样角、屈服应力定义、`r` 的宽/厚塑性应变比及单位。
   - 声明 Orientation 由宿主、适配层还是本构核心处理，禁止重复旋转或默认全局轴。
   - **完成标准**：一个右手材料轴系能唯一解释所有试验方向、参数槽位和剪切对应。
   - **判停条件**：轴系、塑性应变口径或参考应力缺失时，只报“证据不足”，不进行数值转换。

3. **先执行角向拓扑门**
   - 分别列出 `sigma_y(theta)` 与 `r(theta)` 在 0°–90° 的单调段、极值数量、顺序和不确定度。
   - 将观测形状与 Hill48 允许的有限单调/单峰/单谷等形态比较；不要用拟合残差代替形状判定。
   - **完成标准**：对两类曲线分别给出“可表达/不可表达/数据不足”及极值证据。
   - **判停条件**：任一必拟曲线超出模型族拓扑时，停止 Hill48 参数优化并报模型形式错误。

4. **选择 AFR 或 non-AFR 契约**
   - 仅当屈服面与塑性势共用一个函数/参数集时标记 AFR，并保留 `r` 值换算的关联流动前提。
   - 仅当两类曲线各自可表达而共享参数冲突时，再评估 non-AFR，并建立独立的 `yield`/`potential` 契约。
   - **完成标准**：输出函数数量、每套参数的数据来源、流动梯度语义和所需更新器。
   - **判停条件**：用两套参数却仍声称单参数 AFR，或目标宿主无法表达 non-AFR 时，拒绝生成材料卡。

5. **显式转换参数语言**
   - 先标记源/目标语言。对大 `Rij` 转 `F…N`，使用已声明的参考屈服应力和 `tau_y=sigma_y/sqrt(3)` 约定。
   - 按下式计算法向项：

     `F=(R22^-2+R33^-2-R11^-2)/2`

     `G=(R33^-2+R11^-2-R22^-2)/2`

     `H=(R11^-2+R22^-2-R33^-2)/2`

   - 按 `L=3/(2R23^2)`、`M=3/(2R13^2)`、`N=3/(2R12^2)` 计算剪切项，不要把第七个温度列当成系数。
   - 若使用 `r` 路线，核对 `r0=H/G`、`r90=H/F`、`r45=(2N-F-G)/(2(F+G))`；不要由三个 `r` 声称识别了一般三维六参数模型。
   - **完成标准**：源数据经“转换→反算”回到同一强度/`r` 口径，差异低于预先声明的容差。

6. **检查物理域与轴向闭包**
   - 检查所有比值、系数和开方项有限且在定义域内；在偏应力子空间检查二次型半正定性。
   - 验证纯静水应力不屈服，并回算 11/22/33 单轴、23/13/12 纯剪、0°/45°/90° `r` 值及任意角旋转。
   - **完成标准**：全部回算在公差内，静水值为零，旋转前后的物理预测一致，且不出现非凸或负根号。
   - **失败路径**：拒绝该参数集；不要通过取绝对值、夹断特征值或换轴后不记录来“修复”。

7. **只在通过门后拟合并量化残差**
   - 保存试验权重、不确定度、参数约束和初值；同时报告角向屈服应力与 `r` 值的逐点/曲线残差。
   - 把“数据不足”、“参数不可识别”、“模型不可表达”和“优化未收敛”分成四类结论。
   - **完成标准**：交付带版本的参数契约、拓扑判定、反算表、残差图/表和 AFR/non-AFR 语义，而不是只交付六个数。

8. **隔离内置基准与用户实现**
   - 只在弹性、硬化、参数、材料轴、网格、载荷、接触和输出口径同一时，使用 `*POTENTIAL` 作受控基准。
   - 分别标注 `built-in result`、`user-subroutine result`、`fixture only` 和 `quantitatively accepted`。
   - **完成标准**：没有自编源码、材料点残差、状态对照和切线 FD 证据时，结论明确停在“内置基准/夹具”。

## B — 边界 (Boundary)

### 不要在以下情况使用或扩展本 skill

- 不要用本 skill 直接生成、安装或声称验证完整 Hill48 UMAT/VUMAT；只有输入文件和后处理结果时，仍不能证明存在完整用户子程序实现。
- 不要把 Hill48 标量塞进 J2 径向返回壳；流动梯度、塑性乘子、应力修正和切线都必须重推。
- 不要把 Hill48 金属塑性与 Tsai-Hill/Tsai-Wu 强度失效、损伤退化或客观率合并为一个判据。
- 不要把仅针对板料的 `r` 值简式外推为一般三维、平面应变或 non-AFR 通用换算。
- 不要在只有文件名、宣传图、OBJ/CAE/HM 或论坛整理时恢复参数真值或正确性结论。

### 阻断以下失败模式

- 阻断在实验曲线双谷/多峰超出 Hill48 拓扑时继续加点、调权重或宣称拟合收敛即可用。
- 阻断把 `F…N`、大 `Rij`、小 `r` 或 `*POTENTIAL` 第七个温度值按位置直接互换。
- 阻断不声明 AFR、材料轴和应变定义就使用 `r` 值公式，或将 non-AFR 双参数集静默填入 AFR 实现。
- 阻断默认全局轴即轧制轴；当前拉深 deck 未见 `*ORIENTATION`，不能用它借证任意曲面/铺层的材料轴正确。
- 阻断用制耳云图、作业完成或内置 `*POTENTIAL` 运行代替用户更新器的数组、状态、回映和 `DDSDDE` 验证。

## 相关 skills

- **depends-on**: 无——参数语言与模型可表达性可以先于具体积分器独立审计。

- **composes-with**: `cpa-implicit-return-mapping`、`abaqus-tensor-voigt-adapter`——模型族与参数成立后，由一般 `F/G` 回映实现更新，并用表示适配器锁定材料轴和剪切槽位。
